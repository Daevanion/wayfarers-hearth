# Wayfarer's Hearth

An idle adventure card game set in a fantasy medieval village. Collect adventurers, bind a company of three, and send them into the wild while the plaza waits.

## Play

```bash
npm install
npm run dev
```

Then open the printed local address (default `http://localhost:5173`).

Progress is saved in the browser. **Extinguish hearth** in the corner starts over.

## Loop

1. **Crossroads** — send 1–3 adventurers to a location. Time and failure both grow with each success in that country. Ten clearings open the next road.
2. **Success** — gold, materials, a chance at gear, and a chance at a new (or duplicate) adventurer.
3. **Failure** — scant loot, and the company is sent to the church ward until time or gold restores them.
4. **Tavern** — recruit names, dismiss companions, raise a card with likenesses (duplicates).
5. **Blacksmith** — craft, temper, and fit weapons, armor, and charms.
6. **Guild** — collection, set bonuses, and saved banners (decks).

Raising a card deepens its role. Completing a three-card set blesses every adventure; fielding the full set together adds a second, smaller blessing.
